# Assets und Lizenzen

Jede Grafik-, Sound- oder Schriftquelle, die nicht im Code erzeugt wird, kommt hier mit Herkunft und Lizenz hinein. Erlaubt sind nur eigene Werke und CC0.

| Asset                              | Pfad                        | Herkunft                       | Lizenz       |
| ---------------------------------- | --------------------------- | ------------------------------ | ------------ |
| Titel-Szene (Burg, Sterne, Meteor) | `src/render/title-scene.ts` | im Code aus Rechtecken erzeugt | eigenes Werk |
| Favicon (Krone)                    | `index.html`                | Inline-SVG, eigenes Werk       | eigenes Werk |

Schrift: System-Monospace (`ui-monospace`, Cascadia Mono, Consolas) – keine eingebettete Schrift, keine externen Fonts.

Sound: noch keiner. Geplant per Web Audio im Code (ZzFX, MIT-Lizenz), ohne Fremd-Audiodateien.
